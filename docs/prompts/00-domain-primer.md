# Domain primer prompt

I am new to [DOMAIN], and I want to learn while building.

Before writing code, teach me the key design decisions for adding [FEATURE] to this project.

Project context:
[BRIEFLY DESCRIBE THE PROJECT]

Relevant files/components:
- [FILE OR COMPONENT]
- [FILE OR COMPONENT]

Please cover:

1. The main concepts I need to understand.
2. Common beginner mistakes.
3. The minimum good design for this project stage.
4. What would be over-engineering.
5. Which files should probably be involved.
6. Which tests should protect the change.
7. Which packages are reasonable.
8. Which packages should be deferred.
9. A review checklist I can use to critique your future plan.

Constraints:

- Do not edit files.
- Do not propose implementation yet.
- Focus on practical engineering judgment.
- Explain tradeoffs clearly.
